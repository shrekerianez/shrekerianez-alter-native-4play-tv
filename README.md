# PL · Android TV

PL — экспериментальная оболочка Lampa для Android TV с отдельным поиском раздач **PornoLab** через **Jackett** и воспроизведением через **TorrServer**. Возрастное ограничение **18+**.

Независимый проект; не связан с администрациями PornoLab, Lampa, Jackett и TorrServer.

## Архитектура

- **Lampa:** приложение загружает веб-версию https://yumata.github.io/lampa/. Это внешний проект с кодом под GPL-2.0: https://github.com/yumata/lampa-source. Код Lampa в APK не копируется, загружается сайт.
- **PL:** наш отдельный экран с категориями, прямым поиском по трекеру, карточками раздач и управлением пультом (app/src/main/assets/pl-lampa.js). Пункт PL открывается поверх Lampa.
- **Jackett:** индексатор с названием pornolab. Веб-интерфейс Jackett используется для входа на PornoLab. Поиск через Torznab API. В APK хранится только адрес сервера и API-ключ Jackett, который не выдаётся JavaScript.
- **TorrServer:** принимает торрент и отдаёт поток в нативный ExoPlayer (Media3).

## Настройка

1. Установи Jackett на ПК или NAS, добавь индексатор **PornoLab**, авторизуйся на нём и пройди проверку CAPTCHA.
2. Запусти TorrServer на ПК/NAS (обычно порт 8090). Убедись, что Google TV Streamer находится в той же сети.
3. Установи APK PL. Подтверди возраст 18+.
4. В экране PL нажми **Настройки** и введи:
   - IP:порт Jackett (пример: 192.168.1.100:9117);
   - API-ключ из настроек Jackett;
   - IP:порт TorrServer (пример: 192.168.1.100:8090).
5. Введи любой запрос или открой категорию. Поиск идёт только по PornoLab, а не TMDB.

## Скачать APK после сборки

**GitHub → Actions → Build PL APK → последний успешный запуск → Artifacts → PL-debug-apk**.

Скачивается ZIP с файлом app-debug.apk. Это отладочная сборка, подпись непостоянная. Для штатных обновлений потребуется постоянный release-ключ.

## Ограничения PL 0.3.0

- MVP: реальное подключение к пользовательскому Jackett и TorrServer пока не проверено на устройстве.
- Карточки текстовые; постеры, теги, объединение релизов, локальная история просмотра — последующие этапы.
- Некоторые ID форумов могут отсутствовать в актуальной карте категорий Jackett.
- Для TornServer с HTTP Basic auth пока не реализован ввод логина и пароля.
- Воспроизведение зависит от работающих сидов и формата файлов.
- Jackett/TorrServer используют локальный HTTP. Не открывай их в публичный интернет без надёжной защиты.
- Для интерфейса нужен доступ к внешнему веб-сайту Lampa. Автономной копии Lampa внутри APK нет.

Соблюдай местные законы и авторские права при использовании торрент-файлов.
