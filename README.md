# PL · Android TV · автономный MVP 0.4.0

PL — экспериментальное приложение для Android TV / Google TV Streamer 4K (18+). В отличие от версии 0.3.0, не требуется отдельно запускать Jackett, TorrServer, NAS или компьютер.

## Что внутри

- Нативный TV-каталог с разделами PornoLab, навигацией пультом, поиском и выбором раздачи.
- Авторизация в собственном WebView через официальную страницу https://pornolab.net/forum/login.php.
- Загрузка .torrent с того же домена, с локальными cookies аккаунта.
- Встроенный jlibtorrent-android (ARM64, libtorrent), загрузка в приватный кэш приложения.
- Локальный HTTP Range-сервер слушает только 127.0.0.1. Media3 / ExoPlayer получает поток через него.
- Приоритет частей загрузки меняется в зависимости от позиции воспроизведения.
- Кэш находится в каталоге приложения PLCache; свободное место на приставке ограничено.

## Сборка APK

GitHub → Actions → Build PL APK → последний успешный запуск → Artifacts → PL-debug-apk. Внутри ZIP — app-debug.apk.

Приложение рассчитано на arm64-v8a (Google TV Streamer). Debug-подпись не предназначена для постоянных обновлений.

## Как запустить

1. Установи APK на Google TV Streamer 4K.
2. Подтверди возраст 18+.
3. Через меню «Вход на сайт» авторизуйся на PornoLab и пройди CAPTCHA, если она появится.
4. Вернись в PL, открой категорию или найди название.
5. Открой раздачу, нажми «Смотреть в PL» и выбери файл.

## Ограничения и проверки

- Парсинг HTML и авторизацию нужно проверить с действующим аккаунтом на самом устройстве.
- Проверка настоящего воспроизведения, перемотки, сидов и контейнеров MP4/MKV ещё требуется.
- Для больших файлов может не хватить встроенного хранилища Google TV Streamer.
- Постеры, система тегов, история и автоматическая очистка кэша ещё не реализованы.
- Успешная компиляция подтверждает только техническую сборку APK, не работоспособность в любых условиях.

## Исходники и лицензии

Используется Android-библиотека FrostWire jlibtorrent: https://github.com/frostwire/frostwire-jlibtorrent.
Исходники Lampa в PL 0.4.0 не входят. Приложение независимо от сайтов и разработчиков торрент-движков.
