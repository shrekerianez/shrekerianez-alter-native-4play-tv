# PL

Независимое приложение-каталог (18+) для Android TV / Google TV Streamer 4K с управлением пультом и интеграцией с **TorrServer**.

## Возможности версии 0.2.0

- Видеокатегории с официальных страниц PornoLab.
- Навигация стрелками/OK/Назад, поиск, карточка релиза, вход через оригинальную форму сайта.
- Адрес TorrServer задаётся в интерфейсе. Разрешён только IP локальной сети (обычно 192.168.x.x:8090).
- Получение .torrent со страницы после авторизации, передача в TorrServer POST /torrent/upload.
- Получение file_stats через POST /torrents, выбор видеофайла и поток GET /stream/?link=...&index=...&play.
- Встроенный проигрыватель AndroidX Media3 (ExoPlayer).

## Сборка

GitHub Actions: **Build PL APK**. После пуша в main смотри Actions → последний run → Artifacts → PL-debug-apk.
Внутри ZIP лежит app-debug.apk, который можно установить через ADB: adb install -r app-debug.apk.

## Что важно знать

- Это **ранняя тестовая сборка**: её работа с реальными страницами требует испытаний на телевизоре.
- Сайт может менять HTML и доступность страниц; поиск и скачивание требуют авторизации.
- TorrServer должен быть запущен и доступен с Google TV в одной сети.
- Используется HTTP к локальному TorrServer, поэтому доверяй сети. HTTPS используется для самого PornoLab.
- Пароль сайта вводится только в WebView на официальной странице. В коде нет пересылки логина на сторонний сервис.
- При необходимости авторизации на TorrServer (HTTP Basic) текущая версия покажет сообщение об ошибке.
- Приложение не связано с администрацией PornoLab или TorrServer. Соблюдай местные законы и права авторов.

### Ограничения

Вид каталога пока текстово-карточный, без постеров, персональных рекомендаций и дедупликации. Для релиза с несколькими видеофайлами предусмотрен выбор файла. Работа с приватными трекерами зависит от cookies и текущего HTML сайта.
