# PL 0.5.0 · PornoLab TV + TorrServer

PL — независимое экспериментальное Android TV приложение (18+) для Google TV Streamer 4K.

## Архитектура

PL напрямую открывает разделы и поиск на PornoLab. Вход выполняется через WebView на официальной странице сайта. PL получает .torrent, загружает его в TorrServer и передаёт поток в плеер Media3.

- Jackett не нужен.
- NAS и ПК не нужны, если установить TorrServe на том же Google TV Streamer.
- TorrServer остаётся отдельным приложением на этой приставке либо в доверенной локальной сети.
- Библиотека встроенного libtorrent из эксперимента 0.4.0 удалена.
- Экспериментальный Lampa-клиент 0.3.0 больше не используется. PL показывает собственный TV-каталог.

## Установка и настройка

1. Установи TorrServe с официальной страницы https://github.com/YouROK/TorrServe/releases и запусти сервер.
2. Установи APK PL из GitHub Actions.
3. В PL → TorrServer · настройки оставь адрес 127.0.0.1:8090 и нажми «Сохранить и проверить».
4. Через «Вход на сайт» авторизуйся на PornoLab.
5. Открой раздел, найди раздачу, нажми «Смотреть через TorrServer» и выбери видеофайл.
6. Встроенный плеер начнёт воспроизведение полученного от TorrServer потока.

Если сервер на другом устройстве, вместо localhost укажи локальный IP и порт, например 192.168.1.100:8090.

## APK

GitHub → Actions → Build PL APK → успешная сборка → Artifacts → PL-debug-apk. В ZIP находится app-debug.apk.

## Ограничения

- Это тестовый MVP. Настоящие авторизацию, поиск, приём .torrent и воспроизведение надо проверить на приставке.
- Категории и раздачи пока представлены текстовыми карточками, без постеров, тегов и объединения дублей.
- Наличие рабочих сидов, формат файла и скорость интернета влияют на просмотр.
- TorrServer не следует открывать в интернет; предпочтителен localhost.
- HTTP Basic-аутентификация TorrServer пока не поддерживается.
- APK имеет debug-подпись CI, для стабильных обновлений потребуется release-подпись.

PL не связан с администрациями PornoLab или TorrServer. Соблюдай авторские права и местные законы.
